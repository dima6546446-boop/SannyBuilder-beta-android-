# TORSION — Drift Edition

Дрифт-версия TORSION Community Edition (Unity 2020.3 LTS+). Открыл `Assets/Scenes/TestMap/TestMap.unity` → **Play**. Всё остальное (трасса, камера, HUD, дым) создаётся кодом автоматически.

## Управление
| Клавиша | Действие |
|---|---|
| **W** | газ (коробка, сцепление и старт — автоматические) |
| **S** | тормоз; когда остановился — задний ход |
| **A / D** | руль влево / вправо |
| **Пробел** | ручник (блокирует задние колёса — вход в занос) |
| **Left Shift** | клач-кик: держи + газ, отпусти — резкий рывок задней оси |
| **R** | вернуть машину на трассу |
| **C** | камера (погоня / дальняя / бампер) |

## Как дрифтить
1. Разгонись до 60–80 км/ч, повернув, дай газ — зад начнёт уходить.
2. Или: на входе в поворот нажми Пробел на ~0.5 с, потом газ.
3. Помощник сам подруливает против заноса (`Vehicle.assist`, 0…1; 0 — «чистая» физика).
4. Очки: угол × скорость × множитель (растёт, пока держишь занос). Удар о стену обнуляет серию.

## Что изменено в проекте
- `Wheel.cs` — новая модель шины (круг трения: боковое + продольное сцепление в одном бюджете, падение сцепления в скольжении), тормоза, ручник, сцепление с покрытием (`SurfaceGrip`).
- `Vehicle.cs` — управление W/A/S/D, автокоробка и автосцепление, помощники дрифта (противорулевание, ограничение рыскания, срез газа на больших углах), сопротивление воздуха.
- `Gearbox.cs`, `Differential.cs` (самоблокирующийся), `Engine.cs` (множитель мощности `powerMultiplier`).
- Новое: `DriftTrack.cs` (трасса ≈1.5 км: асфальт с разметкой, поребрики, трава, отбойники, арка старт/финиш, деревья, шины, трибуна, холмы + замер кругов), `DriftScore.cs`, `DriftHud.cs`, `DriftCamera.cs`, `TireEffects.cs` (дым, следы, визг шин), `SurfaceGrip.cs`, `DriftBootstrap.cs` (автоустановка при Play).

## Подкрутить
`Vehicle` (инспектор у объекта Vehicle): `assist`, `rearGripScale` (меньше — хвост легче срывается), `steerRate`, `maxBrakeTorque`; `Engine.powerMultiplier`; `Wheel.mu`.
