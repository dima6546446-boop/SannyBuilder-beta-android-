# ЗАНОС — аркадный дрифт в браузере (Three.js)

Самостоятельная игра в духе Russian Car Drift: задний привод, дрифт на очки, гараж, тюнинг, четыре карты, три режима,
прогресс с сохранением. Работает на ПК и на телефоне (экранные кнопки). **Никаких чужих ассетов, названий и звуков:**
вся графика (модели, текстуры, интерфейс) и весь звук (двигатель, шины, удары, музыка) генерируются кодом.
Марки машин вымышленные.

## Запуск одной командой

Нужен Node.js 18+ (проверено на Node 22).

```bash
cd rcd
npm install        # один раз
npm start          # откроется http://localhost:5173 (сервер слушает и по локальной сети — можно играть с телефона)
```

Другие команды:

| Команда | Что делает |
|---|---|
| `npm test` | модульные тесты (vitest): физика, очки, прогресс, мир, режимы, ввод |
| `npm run e2e` | сквозной тест в настоящем Chromium + WebGL: меню → заезд → дрифт → удар → режимы → гараж → сохранение; скриншоты в `docs/screenshots/` |
| `npm run e2e:mobile` | то же на «телефоне» (сенсорный режим, экранные кнопки, раскладка меню) |
| `node tests/tools/recover.mjs <id машины>` | отчёт по поведению машины в заносе (угол, рыскание, скорость) в 6 сценариях «игрока» |
| `npm run build` | продакшн-сборка в `dist/` (статические файлы, можно выложить на любой хостинг) |
| `npm run preview` | запустить собранную версию |

## Управление

Подсказки есть в игре: кнопка «Управление и подсказки» в меню, `H` или `F1` во время заезда.

| Действие | Клавиатура | Геймпад |
|---|---|---|
| Газ / тормоз и задний ход | `W` `↑` / `S` `↓` | RT / LT |
| Руль | `A` `D` `←` `→` | левый стик |
| Ручной тормоз (срыв зада) | `Пробел` | A |
| «Сброс сцепления» (рывок момента) | `Shift` | B |
| Передачи (в режиме «механика») | `Q` / `E` | LB / RB |
| Камера (6 режимов) | `C` | Y |
| Вернуться на старт (серия сгорает) | `R` | X |
| Пауза | `Esc` / `P` | Start |
| Подсказки | `H` / `F1` | Back |

На сенсорных экранах автоматически появляются кнопки: ◀ ▶, ГАЗ, ТОРМ, DRIFT (ручник), РЫВОК, пауза.

Руль на клавиатуре сглаженный: скорость поворота падает со скоростью, возврат в центр быстрее, перекладка в другую сторону —
самая быстрая. У геймпада — мёртвая зона и кривая стика. Дополнительно ход руля сокращается со скоростью, а в заносе
возвращается полностью.

## Что есть в игре

**Физика** (`src/physics/`, все ключевые числа — в одном файле `config.js`):
- заднеприводная модель в плоскости, **4 колеса** с индивидуальной нагрузкой и **переносом веса** (продольным и поперечным),
  раздельное поведение осей (задняя держит в скольжении чуть больше — занос не схлопывается в вертушку);
- комбинированная модель шины (эллипс трения): продольное проскальзывание + угол увода, пик сцепления и спад в скольжении;
- динамика каждого колеса (раскрутка, блокировка тормозом/ручником), двигатель с кривой момента, КПП с автопереключением
  и удержанием передачи в заносе, турбина с лагом, отсечка, блокирующийся дифференциал, «сброс сцепления»;
- срыв зада четырьмя способами: **газом, сбросом газа, ручником, резким поворотом**;
- помощники (регулируются в настройках, «Помощник заноса»): мягкое противорулевание, потолок скорости рыскания,
  срез момента на экстремальных углах и подсадка сцепления зада на больших углах — занос предсказуемо держится,
  плавно выходит и не уходит в вертушку;
- 7 покрытий (асфальт, бетон, мокрый, гравий, грунт, трава, снег) + погода (дождь, снег) меняют сцепление и сопротивление качению;
- **фиксированный шаг 240 Гц** с накопителем: результат не зависит от FPS (проверено тестом на 30/60/144 FPS).

**Столкновения** (`world.js`): капсула из трёх кругов, импульсы с упругостью и трением (с учётом вращения), выталкивание,
стены/отбойники/здания/контейнеры/припаркованные машины как статические препятствия, конусы и бочки — динамические
(их можно сбивать, это не считается ударом).

**Очки** (`scoring.js`): угол × скорость × время. Множитель растёт вместе с серией (+0.5 каждые 2.4 с, максимум ×8),
смена стороны заноса даёт бонус. Серия засчитывается при выходе из заноса или остановке и **сгорает при ударе**.
На экране: очки, серия, множитель, угол; после заезда — сводка (лучшая серия, макс. угол, время в дрифте,
удары, сгоревшие очки, дистанция, рекорд).

**Машины и тюнинг** (`src/game/cars.js`): 8 заднеприводных машин с разным характером (от лёгкой «Копейки» до турбо-купе
«Ракета»), гараж: купить / продать (60% стоимости вместе с тюнингом) / выбрать. Тюнинг 7 деталей по 5 уровней
(двигатель, турбо, подвеска, шины, дифференциал, тормоза, облегчение) — каждая меняет физику. Внешний вид: цвет
(16 + свой), 5 типов дисков, 3 обвеса, 3 спойлера, 4 неона — всё видно в 3D-автосалоне.

**Карты** (`src/game/maps.js`): «Ночная парковка», «Центральная улица», «Промзона» (гравийная яма, скидпад со столбом,
контейнерный лабиринт), «Горный серпантин» (шпильки, отбойники с двух сторон). У каждой — время суток по умолчанию,
которое можно переопределить (день / закат / ночь) и погода (ясно / дождь / снег).

**Режимы:** свободная езда; заезд на очки (таймер, цель, 0–3 звезды); испытания (по 5 на карту: набрать очки, серия без
ударов, удержать угол N секунд, пройти ворота по порядку, очки без единого удара).

**Прогресс** (`progression.js`): деньги и опыт за заезды, 30 уровней, машины и карты открываются по уровню, награды за
испытания (повторно — 25%), рекорды, статистика. Сохранение в `localStorage` (с защитой от повреждённых данных).

**Камеры:** «Сзади» (следует за смесью направления носа и вектора скорости — хорошо видно угол заноса), «Далеко», «Капот»,
«Бампер», «Сверху», «ТВ» (стоящая у трассы камера, перелетающая вслед за машиной).

**Визуал:** дым от шин (цвет зависит от покрытия), следы шин на асфальте, искры при ударах, динамический свет
(фары, фонари, неон, закат/ночь), дождь/снег, эффект скорости (линии, виньетка, расширение FOV, тряска камеры),
тени, отражения неба на кузове. Качество: низкое / среднее / высокое + тени, разрешение, FOV.

**Звук** (`src/audio/audio.js`, Web Audio, всё синтезируется): двигатель по оборотам и нагрузке (+ турбина, хлопки при сбросе
газа), визг шин (по скольжению и покрытию, отдельно гравий), ветер, удары, переключения передач, звуки интерфейса,
процедурная музыка. Громкость: общая / двигатель / эффекты / музыка.

**Интерфейс** (на русском): главное меню, выбор заезда (режим, карта, машина, время суток, погода), гараж (машины,
тюнинг, внешний вид), настройки (графика, звук, управление), пауза, результаты, экран подсказок, HUD со спидометром,
тахометром, передачей, миникартой, таймером и целями.

## Структура проекта

```
rcd/
├─ index.html, vite.config.js, package.json
├─ src/
│  ├─ main.js                 приложение: цикл, состояния, навигация, события
│  ├─ physics/                config.js (все константы) · tire.js · car.js · world.js (коллизии, покрытия)
│  ├─ game/                   cars.js · maps.js · geom.js · scoring.js · progression.js (+сохранение) · session.js
│  ├─ input/controls.js       клавиатура, геймпад, экранные кнопки, сглаживание руля
│  ├─ render/                 scene.js (Gfx) · carModel.js · mapBuilder.js · effects.js · camera.js · textures.js
│  ├─ audio/audio.js          процедурный звук
│  └─ ui/                     screens.js (экраны) · hud.js · style.css
├─ tests/                     physics.test.js · game.test.js (vitest) · e2e.mjs, mobile.mjs (Playwright)
│  └─ tools/                  скрипты настройки физики (recover/drift/ramp) и съёмки скриншотов
└─ docs/screenshots/          скриншоты, снятые e2e-тестом
```

Физика и игровая логика (`physics/`, `game/`, `input/`) не зависят от браузера и рендера — поэтому тестируются в Node.

## Как подкрутить ощущение дрифта

Все ручки — в `src/physics/config.js`:
- `tire.*` — пик сцепления, спад в скольжении (`slideFloor`, `slideFloorRear`, `falloff`), общий уровень (`muScale`);
- `chassis.*` — инерция рыскания, фильтр переноса веса;
- `drivetrain.*` — «аркадная» добавка мощности `powerMul`, инерция двигателя, рывок сцепления;
- `steering.*` — сила помощников (`assistGain`, `yawSoftMax`, `angleLimitBoost`, `angleThrottleCut`);
- у каждой машины (`cars.js`) — масса, развесовка, высота ЦТ, мощность, передачи, сцепление, блокировка диффа.
Силу помощников игрок меняет в настройках («Помощник заноса» 0–100%).

## Тесты и проверка

- `npm test` — 34 теста: разгон всех машин (2.5–12.5 с до 100 км/ч), прямолинейность, торможение, устойчивость поворота,
  срыв зада, **удержание заноса ≥ 2 с** на нескольких машинах, влияние покрытия и тюнинга, независимость от FPS, подсчёт
  очков (угол/скорость/время, множитель, сгорание при ударе, смена стороны), прогресс (уровни, покупка, продажа,
  тюнинг, сохранение/загрузка, повреждённое сохранение), столкновения, режимы, ввод.
- `npm run e2e` — игра запускается в Chromium, программно проезжается сценарий (разгон → занос → очки → удар → пауза →
  камеры → результаты → режим на время → испытание → гараж → покупка и тюнинг → перезагрузка страницы → проверка
  сохранения → три карты с погодой) и снимаются скриншоты.

## Ограничения (честно)

- Физика плоская (без рельефа и подвески по высоте): серпантин извилистый, но ровный. Кузов визуально кренится/клюёт,
  но на геометрию столкновений это не влияет.
- Модели машин и карт процедурные (низкополигональные) — по качеству они не равны художественным 3D-моделям.
  Зато это значит, что в репозитории нет ни одного защищённого ассета.
- Помощники заноса — аркадные (искусственные моменты и подсадка сцепления). Они включены по умолчанию на 70%;
  на 0% машина ведёт себя «сырее» и требует больше навыка.
- Звук синтезируется на лету — он «электронный»; в браузере звук включается после первого клика/нажатия клавиши.
- Мультиплеера, ИИ-соперников и записи повторов нет.
- Проверялось в Chromium (программный WebGL), на реальной видеокарте и в мобильных браузерах сцена будет работать
  заметно плавнее; на очень слабых телефонах выберите «Низкое» качество и уменьшите разрешение в настройках.

## Источники и лицензии

Используются только открытые библиотеки: [three.js](https://threejs.org) (MIT), [Vite](https://vite.dev) (MIT),
[Vitest](https://vitest.dev) (MIT), [Playwright](https://playwright.dev) (Apache-2.0, только для тестов). Всё остальное
(код, графика, звук, музыка) создано в этом репозитории.
