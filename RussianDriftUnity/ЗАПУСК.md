# Пошаговый запуск Russian Drift

1. Установите Unity Hub и Unity **6.0 LTS (6000.0.x)** с модулем **Android Build Support** (OpenJDK + Android SDK & NDK Tools).
2. Распакуйте архив. Внутри будет папка `RussianDriftUnity`.
3. Unity Hub → Add → Add project from disk → выберите `RussianDriftUnity`. Если Hub предложит сменить версию на вашу 6000.0.x — согласитесь.
4. Первый импорт идёт несколько минут (скачиваются пакеты URP, Input System, UGUI).
5. После импорта скрипт сам создаст сцены, данные, URP-ассеты и настройки Android (смотрите Console: «Setup complete»). Если Unity попросит включить новую Input System и перезапуститься — нажмите Yes.
6. Если сцен `Assets/Scenes/Boot.unity` нет — меню `Tools ▸ Drift ▸ 1. Setup Project (everything)`.
7. Откройте `Assets/Scenes/Boot.unity` → Play. Управление: W/S газ/тормоз, A/D руль, Space ручник, Left Shift «пинок» сцепления, C камера, Esc пауза.
8. Ошибки компиляции в Console (если будут) пришлите мне текстом — исправлю.
9. Сборка на телефон: `File ▸ Build Profiles ▸ Android` (или сразу `Tools ▸ Build ▸ Android APK`). Результат: `Builds/Android/RussianDrift.apk`. Скопируйте на телефон и установите (разрешите установку из неизвестных источников).
