# Russian Drift — аркадный дрифт для Android (Unity 6.0 LTS, URP)

Игра в духе *Russian Car Drift*: открытый город / промзона / серпантин, дрифт на «классике», «девятках» и купе,
гараж с тюнингом, прогрессия, дрифт-баттлы с ИИ, тайм-аттак, ежедневные задания, смена дня/ночи и погода.
Весь контент (модели, текстуры, звук, музыка) **генерируется кодом** — проект играбелен сразу после импорта, без внешних ассетов.
Что и куда можно подключить — в [`ASSETS.md`](ASSETS.md).

> Проект лежит в папке `RussianDriftUnity/` репозитория (в корне репозитория находится не связанное с ним Android-приложение,
> поэтому Unity-проект изолирован в подпапке). **Открывайте в Unity Hub именно эту папку.**

## Быстрый старт

1. Unity Hub → *Add project from disk* → `RussianDriftUnity/`. Версия: **6000.0.x LTS** (в `ProjectVersion.txt` — 6000.0.23f1, любая 6000.0.x подойдёт).
   Модуль **Android Build Support** (с OpenJDK и SDK/NDK) должен быть установлен.
2. При первом открытии скрипт `Scripts/Editor/DriftMenu.cs` сам выполняет **Tools ▸ Drift ▸ 1. Setup Project (everything)**:
   * создаёт базовые материалы, ScriptableObject-данные (8 машин, 7 апгрейдов, косметика, 9 трасс) и реестр `GameCatalog`;
   * создаёт URP-ассеты **Low / Medium / High** (SSAO на Medium/High) и назначает их уровням качества;
   * настраивает Player Settings (Android, ARM64, IL2CPP, min API 26, Vulkan → OpenGLES3, ASTC, Linear, ландшафт);
   * включает **новую Input System** (Unity может предложить перезапуск редактора — согласитесь один раз);
   * собирает сцены **Boot, MainMenu, Garage, GameWorld** и добавляет их в Build Settings (Boot — первая);
   * генерирует префабы машин в `Assets/Prefabs/Cars`.
   Если что-то пошло не так — запустите пункт меню вручную (он идемпотентен). Отдельные шаги тоже есть в меню `Tools ▸ Drift`.
3. Откройте `Assets/Scenes/Boot.unity` и нажмите **Play** (в редакторе управление: `W/S` газ/тормоз, `A/D` руль, `Space` ручник,
   `Left Shift` сцепление-«пинок», `E/Q` передачи (если коробка ручная), `C` камера, `Esc`/`P` пауза; геймпад тоже работает).
4. **Сборка APK/AAB одной кнопкой:** `Tools ▸ Build ▸ Android APK` (или `AAB (Play Store)`, или `APK (development)`).
   Результат: `Builds/Android/RussianDrift.apk|aab`. Подпись: переменные окружения `RD_KEYSTORE_PATH`, `RD_KEYSTORE_PASS`,
   `RD_KEY_ALIAS`, `RD_KEY_PASS`; без них используется debug-keystore. Для CI:
   `Unity -batchmode -quit -projectPath RussianDriftUnity -executeMethod RussianDrift.EditorTools.BuildScript.BuildAndroidCli` (`RD_BUILD_AAB=1` для AAB).

## Что внутри

| Требование | Реализация |
|---|---|
| Физика дрифта | Собственная модель: подвеска на рейкастах (пружина + демпфер + ограничитель хода), шины с **кругом трения** и кривой «угол увода → сцепление», перенос веса от нагрузки пружин, ручник, «пинок» сцепления, зависимость сцепления от покрытия/дождя/луж. `Vehicle/VehicleController.cs` |
| Помощники | Steering Assist (контр-руление), Drift Assist (демпфирование заноса > 48°, удержание передачи), ABS, TCS — переключаются в настройках. Авто/ручная коробка |
| Трансмиссия | `Vehicle/Drivetrain.cs`: кривая момента по оборотам, 5–6 передач, отсечка, **турбо** с лагом, стравливанием (psshh) и **выстрелами** из выхлопа, дифференциал (open ↔ lock), RWD/AWD |
| Повреждения | Деформация вершин кузова в точке удара, отлетающие детали (бамперы, зеркала, спойлер), царапины-декали, износ краски (`VehicleDamage`) |
| Очки дрифта | Угол × скорость × время, растущий множитель, бонус за смену направления, зоны ×1.6–2, штраф/обрыв цепочки при ударе, near-miss в трафике (`DriftScorer`) |
| Камеры | Хвостовая (динамический FOV, «подхват» вектора скорости), салон, капот, боковая киношная + линии скорости и тряска (`CameraRig`) |
| Мир | Город 5×5 кварталов (панельные дома, гаражи, АЗС, парковки, рынок, парк), промзона (заводы, трубы, контейнеры, шины), серпантин с горой, ночной город. Процедурно, по сидам; пресеты кварталов — `CityBuilder` |
| Режимы | Свободная езда, дрифт-трассы, тайм-аттак (круги/чекпоинты/медали), дрифт-баттл с ИИ (4 сложности), ежедневные задания |
| День/ночь, погода | `DayNightCycle` (солнце/луна, процедурное небо, звёзды, ambient, туман), `WeatherSystem` (дождь, туман, мокрый асфальт, лужи → брызги и −сцепление), окна домов светятся ночью, фонари, фары + конусы лучей |
| ИИ и трафик | `AIDriver` — следование по пути + дрифт-закон руления (угол заноса + ошибка курса), старт заноса ручником; `TrafficManager` — полосы, светофоры, дистанция, near-miss |
| Автомобили | 8 машин (Копейка, Пятёрка, Девятка, Десятка, Волжанка, Универсал-Турбо, Ронин, Ракета) — оригинальные названия, свои `CarDefinition`; процедурные модели с **LOD0/1/2**, PBR-материалами, вращающимися колёсами, фарами/стопами/поворотниками/задним ходом |
| Тюнинг | Двигатель, турбо, подвеска (+клиренс, развал), тормоза, шины, дифференциал, облегчение; привод RWD/AWD; обвесы (3), спойлеры (4), диски (5 + цвет), краска (палитра + HSV), плёнки (6), винилы/наклейки (5), неон (5), тонировка, номера (генерация российского знака) |
| Гараж | 3D-витрина, вращение камеры жестом, предпросмотр с покупкой, сохранение |
| Персонаж | Процедурный скелетный человечек (skinned mesh, 8 костей), походка/сидение/ликование; анимация посадки и выхода; кастомизация (одежда, кепка, очки, цвета). Зрители у зон дрифта реагируют на красивые заносы |
| Графика | URP, ACES, Bloom, Color Adjustments, Vignette, **Motion Blur** по скорости, SSAO (renderer feature), мягкие тени, realtime Reflection Probe, SRP Batcher, GPU Instancing на базовых материалах, LOD, объединение статических мешей по материалам и чанкам, ограничение дальности теней |
| Эффекты | Дым из-под колёс, **следы шин** (пул динамических лент), искры, дым и **пламя** выхлопа, брызги из луж, тепловое свечение турбо, объёмные лучи фар, неон-подсветка и отражения на мокром асфальте |
| Звук | Процедурный: 3 слоя двигателя по оборотам/нагрузке (питч + кроссфейд), свист турбины, стравливание, выстрелы, визг шин по заносу, удары, ветер, дождь, городской фон, UI; **музыка** — 5 синтезируемых треков и плейлист (рендер в фоновом потоке) |
| Интерфейс | Главное меню, выбор режима/трассы/сложности, гараж (машины/тюнинг/вид/водитель), магазин, ежедневные награды + задания, достижения, настройки, пауза, результаты, HUD со спидометром/тахометром/передачей/турбо, очками и комбо, мини-картой, **перемещаемыми и масштабируемыми** кнопками |
| Управление | Новая Input System: кнопки, **наклон телефона** (калибровка/инверсия), экранный руль, геймпад, клавиатура |
| Мета | Валюта, XP/уровни, разблокировка по уровню и цене, 13 достижений, ежедневная награда (7 дней), 3 задания в день |
| Сохранения | JSON → XOR-обфускация ключом устройства → HMAC-SHA256; зеркало в PlayerPrefs; при подмене — откат на зеркало, иначе новый профиль; `ICloudSaveService` (локальная заглушка) |
| Монетизация | `IAdService`, `IIapService`, `ICloudSaveService` + заглушки `StubAdService`, `StubIapService` (в релизе покупки отклоняются — заглушка не выдаёт бесплатную валюту), без привязки к SDK |
| Качество | `QualityManager` определяет класс устройства (RAM/ядра/VRAM/API) и применяет Low/Medium/High; `AdaptiveQuality` следит за FPS и снижает render scale/уровень. Цель: 60 FPS на среднем, 30 на слабом |

### Архитектура (asmdef)

```
RussianDrift.Core   — события, сервисы, пул, сохранения, настройки, локализация, данные (SO), ввод, процедурные текстуры/меши
RussianDrift.Vehicle← Core   — физика, трансмиссия, модель авто, повреждения, эффекты, камера, очки дрифта
RussianDrift.Audio  ← Core, Vehicle
RussianDrift.World  ← Core, Vehicle   — генерация мира, свет/погода/постобработка, зрители, персонаж, зоны, чекпоинты
RussianDrift.AI     ← Core, Vehicle, World   — ИИ-гонщик, трафик
RussianDrift.Meta   ← Core   — профиль, экономика, задания, достижения, заглушки сервисов
RussianDrift.UI     ← всё   — контроллеры сцен, HUD, меню, гараж, режимы
RussianDrift.Editor ← всё (Editor only) — автосборка сцен/данных/URP/префабов, настройки, сборка Android
```
Модули связаны через `GameEvents` и `Services` (Vehicle не знает про UI/Meta). Данные — ScriptableObject (`CarDefinition`,
`UpgradeDefinition`, `CosmeticDefinition`, `TrackDefinition`) + реестр `Resources/GameCatalog.asset`; при его отсутствии каталог
строится кодом (`DefaultCatalog`), поэтому игра запускается даже до шага Setup.

Структура папок: `Assets/Scripts/{Core,Vehicle,AI,UI,Audio,World,Meta,Editor}`, `Assets/{ScriptableObjects,Prefabs,Scenes,Materials,Art,Resources}`.

## Принятые решения (автономный режим)

* **Unity-проект в подпапке** `RussianDriftUnity/`, чтобы не затрагивать существующее Android-приложение в корне репозитория.
* **Сцены содержат один контроллер**, весь контент строится в рантайме (детерминированно по сиду). Так сцены не зависят от потерянных
  процедурных ассетов и собираются одной командой.
* **Локализация RU/EN — собственная** (`Loc` + `LocTable`, ключи 1-в-1 как в StringTable). Пакет Unity Localization требует ручной
  настройки таблиц/локалей в редакторе; свой слой работает без настройки и так же легко мигрирует на пакет.
* **Запечённое освещение и окклюзия:** город процедурный и создаётся в рантайме, поэтому lightmap/occlusion bake неприменим. Вместо этого:
  реалтайм солнце/луна с мягкими тенями на ограниченной дистанции, ambient-градиент, **realtime Reflection Probe**, статичные меши объединены
  по материалам/чанкам, **дистанционный culling чанков** (`ChunkCuller`) + far-plane по качеству, LOD у машин. Если нужен классический bake —
  сгенерируйте город в редакторе и сохраните меши как ассеты (структура `WorldBuilder` это позволяет).
* **Animator/Timeline:** посадка/выход и толпа — процедурная скелетная анимация (skinned mesh, код). Никаких внешних клипов не нужно;
  для Mixamo-персонажа см. `ASSETS.md`.
* **Сцепление и «аркадность»:** тяга ×1.3 (`Drivetrain.ArcadePower`), «power-slide» — газ и пинок сцепления разгружают поперечное сцепление
  задних колёс, когда машина уже в заносе; параметры подобраны на планарной симуляции (Python-порт модели шин) и требуют финальной
  настройки на устройстве — все числа вынесены в `CarDefinition`/константы.
* **Частицы** используют встроенные шейдеры `Sprites/Default` и `Mobile/Particles/Additive` (они добавляются в *Always Included Shaders*),
  фары/неон — `URP/Unlit` с HDR-цветом (Bloom подхватывает). Материалы с ключевыми словами (`_EMISSION`) заранее лежат в `Resources/Materials`,
  чтобы варианты шейдера не вырезались при сборке.
* **Покупки:** заглушка IAP в релизе всегда отказывает; в редакторе/Development выдаёт валюту для теста.
* **Unity 6:** используются обёртки `Compat` для переименованных членов Rigidbody (`linearVelocity`, `linearDamping`) и `FindFirstObjectByType`;
  `PhysicsMaterial` под `#if UNITY_6000_0_OR_NEWER`.

## Проверка

В среде автора **не было Unity Editor**, поэтому игра не запускалась. Выполнено: полная компиляция всех сборок (по asmdef-зависимостям)
против API модулей Unity 2021.3 (`UnityEngine.Modules`, `UnityEngine.UI`) с заглушками для Input System, URP, Volume и UnityEditor —
ошибок нет; планарная симуляция модели шин (дрифт ручником/пинком/газом, устойчивость) и закона руления ИИ на круге промзоны;
запуск логики трансмиссии/трекпатов под Mono; численная проверка порядка вершин/нормалей всех мешей (см. `Tools~/Verification`). Не проверялось в реальном Unity: внешний вид UI-раскладок, баланс физики, производительность на устройствах, точные имена
свойств URP-ассетов в `UrpAssetBuilder` (отсутствующие свойства просто пропускаются). Если при первом открытии появятся ошибки компиляции
из-за отличий версии пакетов (URP 17.0.x / Input System 1.11.x), они, скорее всего, точечные — исправляйте по тексту ошибки.

## Известные ограничения / идеи

* Облачная синхронизация — только интерфейс + локальная симуляция (Google Play Games Saved Games подключается реализацией `ICloudSaveService`).
* Нет настоящих внешних моделей/звуков — см. `ASSETS.md` (хуки: `CarDefinition.modelPrefab`, `Resources/Audio/<key>`, `Resources/Textures/<key>`).
* Мини-карта рендерит сцену сверху 6–8 раз в секунду (дорого на очень слабых устройствах — отключается в настройках).
