# ЗАНОС — Unity-версия (порт браузерной игры из `../rcd`)

Аркадный дрифт на заднем приводе: 8 машин, гараж с тюнингом и кастомизацией, 4 карты, режимы «свободная езда / заезд на очки /
испытания», очки за угол × скорость × время, прогресс с сохранением, 6 камер, дым / следы / искры, процедурный звук, интерфейс на русском.
**Ни одного внешнего ассета:** модели, текстуры, звук и музыка создаются кодом. Названия машин вымышленные.

## Запуск

1. Unity **6000.0 LTS** (проверялось по API 2021.3+; проект написан без URP-специфики и работает на Built-in и URP).
2. Unity Hub → *Add project from disk* → папка `ZanosUnity`. При первом открытии скрипт `ZanosSetup` сам настроит Android, создаст пустую
   сцену `Assets/Scenes/Main.unity` и добавит шейдеры в сборку.
3. Открыть `Assets/Scenes/Main.unity` → **Play**. Игра создаётся сама (`ZanosBootstrap`) — никакие объекты в сцене не нужны.
4. APK: меню **Zanos → Собрать Android APK** (нужен Android Build Support; файл появится в `Builds/Zanos.apk`).

Управление: `W/S` газ/тормоз, `A/D` руль, `Пробел` ручник, `Shift` рывок момента, `Q/E` передачи (механика), `C` камера, `R` на старт,
`Esc` пауза, `H` подсказки; геймпад (RT/LT, левый стик, A — ручник, B — рывок, Y — камера, X — на старт, Start — пауза); на телефоне —
экранные кнопки (мультитач). Ввод работает и с пакетом Input System, и со старым Input Manager.

## Устройство

```
Assets/Scripts/Core   — чистый C# без UnityEngine (asmdef noEngineReferences): физика, мир/коллизии, очки, сессия, прогресс, каталог машин
Assets/Scripts/Game   — слой Unity: приложение, интерфейс (IMGUI), HUD, карта и машина из примитивов, камера, эффекты, звук, ввод, сохранение
Assets/Resources/Zanos/Maps — карты (JSON), экспортируются из браузерной версии
Assets/Editor         — автонастройка и сборка APK
Tools~/Parity         — сверка физики с браузерной версией и тесты ядра (Mono)
Tools~/MeshCheck      — проверка, что процедурные меши обращены наружу (правило Unity: грани по часовой стрелке)
Tools~/UnityCheck     — проверка компиляции без Unity (UnityEngine.*Module.dll + заглушка Input System)
```

Данные не дублируются вручную: `node ../rcd/tools/export-unity.mjs` генерирует `CarCatalog.cs` и JSON карт из тех же файлов, что использует браузерная версия.

## Что проверено (и что нет)

Проверено на Mono без Unity (нужны `mono` и `mcs`):

| Проверка | Команда | Результат |
|---|---|---|
| **Физика C# ≡ физика JS** на 5 сценариях (разгон, занос на ручнике, скандинавский разворот, торможение, тюнингованная «Ракета») | `node ../rcd/tools/parity-dump.mjs && Tools~/Parity/run.sh` | расхождение ≤ 4·10⁻¹² |
| Тесты ядра: разгон всех машин, удержание заноса, очки, стена/конус, покрытия и погода, режимы, прогресс (покупка/продажа/тюнинг/награды) | `Tools~/Parity/run-core-tests.sh` | 27 проверок |
| Меши (бокс, цилиндр, колесо, лента, диск, выдавливание) обращены наружу | `Tools~/MeshCheck` (см. скрипт ниже) | все |
| Компиляция всего C# против UnityEngine 2021.3 (оба режима ввода) | `Tools~/UnityCheck/check.sh` | без ошибок |

**Не проверено:** сам запуск в Unity Editor и на устройстве — в среде разработки Unity нет. Слой Unity (`Scripts/Game`, `Editor`) гарантированно
компилируется, а вся игровая логика и физика подтверждены тестами; визуальная часть (расположение элементов IMGUI, внешний вид
процедурных моделей, баланс звука) требует вашей проверки глазами. Если что-то выглядит не так — это правится в `ZanosUi.cs`,
`CarView.cs`, `MapView.cs`, `AudioSynth.cs` без затрагивания ядра.

Проверка мешей: `cd Tools~/MeshCheck && mcs -out:/tmp/meshcheck.exe UnityShim.cs Check.cs ../../Assets/Scripts/Game/MeshBuilder.cs && mono /tmp/meshcheck.exe`.

## Ограничения

- Интерфейс на IMGUI (без Canvas/префабов) — работает везде, но выглядит проще браузерной версии; миникарта «север сверху».
- Графика процедурная (боксы/цилиндры/выдавливания): без постобработки URP, без цветокоррекции и bloom (в браузерной версии они есть).
- Физика плоская, без рельефа. Помощники заноса аркадные (настройка «Помощник заноса» в меню).
